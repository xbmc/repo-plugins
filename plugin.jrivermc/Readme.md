# JRiver Media Center Add-on for Kodi

The [JRiver Media Center](https://www.jriver.com/index.html) add-on for [Kodi](http://kodi.tv) allows you to browse and play the media files in your JRiver MC library locally on the device running Kodi.
[JRiver MC](https://www.jriver.com/download.html) must be installed and running on a computer accessible over the network.
[Media Network](https://wiki.jriver.com/index.php/Media_Network) must be enabled for your library.
For help please see the [JRiver Wiki](https://wiki.jriver.com/index.php/Category:Frequently_Asked_Questions) or [Interact Forum](https://yabb.jriver.com/interact/index.php).
