# Game Manuals (REG-Vault)

Answers Kodi when it goes looking for a manual for a game that has none, using
the [REG-Vault](https://regvault.org) catalogue.

There is nothing to open here. Play a game, choose Manual from the game menu,
and Kodi asks this add-on what it can find. Kodi stores whatever you pick.

Games are matched by an MD5 of the ROM itself, so a manual is either the right
one or it is not offered. A ROM that is a different dump, region or revision to
anything catalogued is a miss rather than a wrong answer. The system is guessed
from the folder name first and the file extension second.

## Limits worth knowing

- The catalogue holds no manual for every game. Homebrew, hacks and aftermarket
  releases are mostly absent.
- Large disc images are skipped by default: hashing one takes minutes and those
  systems are rarely keyed by it.
- The free tier allows 1,000 lookups a day per IP address, so a household
  shares one allowance. A search costs one or two.

Manuals remain the copyright of their publishers. REG-Vault catalogues them as
a preservation archive.
